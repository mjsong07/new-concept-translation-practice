# new-concept-translation-practice 项目知识

开始项目任务时先阅读根目录 AGENTS.md。根据任务按需读取：

- 需要理解结构和模块边界时，读取 references/architecture.md。
- 需要启动、测试或发布流程时，读取 references/workflows.md。
- 需要复用历史决策或排查已知问题时，读取 references/decisions-and-pitfalls.md。
- 需要快速追溯 Codex 历史结论时，读取 references/history-summary.md。
- 需要查看完整用户与助手对话时，读取 references/chat-history/README.md，再按会话链接打开对应归档。

以当前代码和实际验证结果为准。发现知识过期时，在完成任务后同步更新对应参考文档。
